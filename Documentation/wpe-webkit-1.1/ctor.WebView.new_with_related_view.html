Description [src]

Creates a new web view sharing the same configuration and web process as another.

A related view should always be set when creating a WebKitWebView in a handler for the WebKitWebView::create signal.

The new view will also have the same WebKitUserContentManager and WebKitSettings as the related web_view.

Available since:2.4
